## Getting started

Install the tool with `npm install lantern`, then read the [setup guide](https://example.com/docs/setup). It works on **every** platform, and *most* shells.

- Fast start
- Small config
  - one file
  - no state_dir needed

1. Clone it
2. Run it

```shell
lantern init --name demo
lantern run
```

> Tip: run `lantern doctor` first.

| Option | Default |
| --- | --- |
| port | 8080 |
| quiet | false |

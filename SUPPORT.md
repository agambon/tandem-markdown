# Support

## Documentation

Before opening an issue, check the guides included with Tandem Markdown:

- [Using Tandem Markdown](GUIDE.md): views, editing, tables, paste, diagrams, settings, and known limits.
- [When an agent or another program changes your note](WORKING_WITH_AGENTS.md): merges, conflict files, backups, and agent instructions.
- [Syntax reference](SYNTAX.md): supported markdown syntax and the settings that control each addition.
- [Known issues](KNOWN_ISSUES.md): known limitations and workarounds.

## Reporting a Bug or Requesting a Feature

Open an issue on GitHub: https://github.com/agambon/tandem-markdown/issues

For bug reports, please include:

1. Output from **`Tandem Markdown: Copy Diagnostics`** in VS Code's Command Palette (copies VS Code, OS, and extension versions, active settings, and redacted log entries with no note text).
2. The smallest markdown snippet and steps that reproduce the problem.

## Security Issues

Please do not report security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md) for private reporting instructions.
